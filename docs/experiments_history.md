# 历史实验记录（Historical Experiments）

本文件保存 2026-11-05 这一轮调试/验证实验的记录，便于写论文时追溯。

> 对应的**可机读数据**（逐 step `metrics.jsonl`、`run_summary.json`、smoke 结果）已按新的
> run-record 格式重建到仓库 `runs/` 目录：
> `runs/20261105_smoke_test/`、`runs/20261105_tiny_fd/`、`runs/20261105_tiny_jvp/`。
> 以后用 `bash scripts/launch_run.sh <name> <config>` 启动的运行会自动写入 `runs/<name>/`。


> 说明：这些实验都是在**单卡 RTX 5090（共享机，GPU 被其他用户占用约 23GB）**上做的，
> 主要目的是验证"Chebyshev 多项式参数化 u + 有限差分（FD）替代 `jax.jvp`"这套重构
> 在数值和训练动力学上是否成立，**不是最终的 ImageNet 结果**。

## 1. `smoke_test.py`：接口 / FD 数值自检

小模型：`pmfDiT_tiny`（32×32，patch 8，hidden 64，depth 4，aux_head_depth 1），
`cheb_order=3`，中心差分扫 δ 与 `jax.jvp` 对比。

| 运行 | 最佳 δ | 最小相对误差 | 说明 |
|---|---|---|---|
| CPU（fp32） | 3e-3 | **4.9e-5** | δ=1e-3 时 6.7e-5；δ=3e-2 时 5.1e-3 |
| GPU（默认 TF32） | 3e-2 | 5.7e-3 | δ 越小误差越大（δ=3e-4 时 0.168）：TF32 舍入被差商放大 |
| GPU（`JAX_DEFAULT_MATMUL_PRECISION=highest`） | 3e-3 | **5.0e-5** | 与 CPU 完全一致 → 证实差异来自 TF32 |

**结论**：FD 实现正确；GPU 上默认 TF32 时 FD 的 δ 需要放大到 ~0.02，或改用高精度矩阵乘。
smoke 里 fd 与 jvp 两种训练模式的 loss/grad 完全一致（loss=0.999998，
grad_norm 0.279621 vs 0.279619）。

**观察**：随机合成数据下 `loss_vel` 从 1.333 降到 ~1.19（缺少真实学习信号，属正常）；
`u_abs`/`du_dt_abs`/`loss_reg` 持续增长（模型在拟合噪声），真实数据实验需重点监控，
必要时把 `reg_lambda` 从 0 调成 1e-3。

## 3. 失败记录：B/16 batch 32 显存不足（共享卡）

在 `pMF_B_16_debug`（batch 32）上：参数 120,006,016、采样编译 14s、
`p_train_step` 编译 82s，但执行时 OOM——XLA 报该 step 需 ~12.5–16.4GB，
而当时 GPU 空闲仅 ~8.8GB（其他用户占用 23.6GB）。后续把 debug 配置降到
batch 8（及 tiny 替代）以适配共享卡。
